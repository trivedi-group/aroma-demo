# AROMA OlfactoCards synthetic demonstration

A static demonstration of the AROMA OlfactoCard site. The 29 compound identities are real (PubChem). Every measurement shown is synthetic and generated by a script, and the site says so in a banner on every page. Odour descriptors are from Arctander 1960 as distributed in the Pyrfume archive (CC BY-NC 4.0, non-commercial use only).
